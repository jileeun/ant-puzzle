# 데굴데굴 쇠똥구리 — 게임 기획서 (GDD)

## 1. 개요
| 항목 | 내용 |
|---|---|
| 장르 | 캐주얼 순서 퍼즐 (대기열 선택 + 길 열기) |
| 플랫폼 | 모바일 웹 (세로 420×800, 단일 HTML) |

| 콘텐츠 | 기본 52스테이지 (도트 그림 32 + 큰 그림 20) + 📷 내 사진 스테이지 |
| 모드 | 혼자 하기 / 협동 온라인 / 경쟁 온라인 (PeerJS 폰끼리 연결) |

## 2. 화면 구성
- **위 2/3 그림판**: 음식 조각으로 그려진 그림. 바깥에 쇠똥구리가 다니는 네모 길.
- **일터 5칸**: 대기열에서 고른 쇠똥구리가 들어가는 자리. 칸 위에 집(일꾼이 나오는 곳).
- **대기열 3줄**: 맨 위 쇠똥구리만 고를 수 있음. 숫자 = 가져올 음식 수.
- **굴**: 그림판 아래 가운데. 일꾼이 음식을 굴려 넣는 곳.
- **상단 바**: 뒤로, 🎒 부스터 가방(개수 배지, 혼자 하기) 또는 ? 아이템 도감(경쟁), 스테이지 이름(허들은 ⚠/🔥 표시), 진행 막대, 배속(1·2·3·5·9), 다시.
  - 버튼은 그림판 위에 올리지 않는다 (그림과 쇠똥구리를 가리지 않게).
- **안내 배너(그림판 위쪽)·안내 문구(그림판 아래쪽)**: 상자는 글 길이에 맞춰 넓어지고, 넘치면 줄을 나눈다.
  보여 주는 시간은 글자 수에 맞춤 = `1.2초 + 글자 수 × 0.11초` (최소 2.4초, 스테이지 시작 배너는 최소 4초, 최대 7초).

## 3. 핵심 규칙
1. 대기열 맨 위 쇠똥구리를 누르면 빈 일터로 감.
2. 일터 쇠똥구리는 숫자만큼 일꾼을 0.4초 간격으로 내보냄.
3. 일꾼은 집 → 바깥 네모 길 → **그림 바깥과 이어진 빈 칸**을 따라 꺾어 들어가 같은 색 음식을 집음.
   (바깥에서 닿지 않는 음식은 못 가져감 = 바깥쪽부터 먹어야 안쪽 길이 열림)
4. 집은 음식은 공처럼 굴려 가장 가까운 출구로 나가 굴로 넣음.
5. 일꾼을 다 보낸 일터 쇠똥구리는 사라져 칸이 빔.
6. **사슬**: 같은 줄 이웃 두 쇠똥구리가 묶이면 둘 다 맨 위에 있고 빈 칸이 2개 있어야 고를 수 있음.
7. **클리어**: 음식을 모두 굴로 옮김. **실패**: 일하는 일꾼이 없고, 일터 쇠똥구리가 닿을 음식이 없고, 더 고를 수도 없음 (0.9초 유지).

### 3.1 이동 연출 규칙
- **옆으로 갈 때와 아래로 갈 때는 옆모습**(걷기 / 물구나무 서서 공 굴리기)으로 그린다 — 옆모습이 "똥을 굴리는" 느낌이 가장 잘 남.
  아래로 갈 때 바라보는 쪽은 마지막으로 옆으로 걷던 방향. 위에서 본 모습은 위로 올라갈 때만 쓴다.
- 마주 오는 쇠똥구리와 겹치지 않게 진행 방향 오른쪽으로 차선을 비켜 걸음.
- **바깥 네모 길 위에서는 방향과 상관없이 항상 그림 안쪽으로 비켜 걸음** (액자 테두리 선을 밟지 않음).
- 같은 방향 앞 쇠똥구리와 안전거리 유지, 집 앞이 붐비면 출발 대기.

## 4. 스테이지 생성
- 그림 → 음식 격자 (최대 28×30칸, 테두리선 포함).
- 쇠똥구리 순서는 **실제 플레이를 흉내 낸 시뮬레이션**으로 만듦 → 반드시 풀 수 있는 순서가 기본.
  - 동시에 일하는 칸은 보통 `min(3, 일터칸-1)`, 막히면 일터 칸 수까지.
  - 새 쇠똥구리는 "지금 닿을 수 있는 색"으로만 만든다.
- 이후 난이도 손잡이로 순서를 흔든다:
  - `jitter`: 이웃 쇠똥구리 순서를 바꿀 확률 / `jitterSpan`: 최대 몇 칸 멀리 바꾸는지
  - `link`: 줄마다 사슬이 생길 확률 / `ants`: 목표 쇠똥구리 수
  - `seed`: 같은 값이면 항상 같은 순서 (QA가 고른 값을 표에 고정)

## 5. 레벨 디자인: 장(章)마다 하나씩 배우기 ★ (2026-11-11 개편 · 2026-11-12 초반 난이도 완화, 1~3장 적용)

### 5.A 왜 바꿨나
이전 방식(번호 패턴으로 ⚠/🔥, 기믹은 %지점에 무작위)은 퍼즐을 푸는 재미가 없었다.
- 생성기가 "지금 먹을 수 있는 색"으로만 순서를 만들어서, 보통 스테이지는 생각 없이 눌러도 실패율 0%.
- 기믹을 **써야만** 풀리는 판이 없었다 → 기믹이 장식일 뿐, 배울 것도 고민할 것도 없음.

### 5.B 원칙
1. **장마다 배울 것 하나**: 소개 → 강제(그걸 모르면 막힘) → 변주 → 앞에서 배운 것과 조합 → 장 시험.
2. **판으로 가르친다**: 시작 배너는 "무엇을 보면 되는지"만 (정답 X). 막히면 실패 화면에 그 판의 요령(💡 hint).
3. **반대 검증**: 실제 엔진 자동 플레이로 "배울 것을 모르는 전략은 막히고, 배운 대로 하면 풀린다"를 확인 (`qa.engine`).
4. **시험은 배운 것만으로 풀려야 한다**: 안 가르친 걸 요구하지 않음.
5. **보이게 한다**: 닿는 음식이 없는 일터 쇠똥구리는 💤 (칸을 막고 있음이 보임). 칸 수를 줄인 판은 자물쇠가 아니라 흙으로 메운 칸.
6. **재미를 난이도로만 조절하지 않는다** (2026-11-12 추가). 피드백: "초반이 너무 어렵다. 재미가 어려운 난이도로만 조절되면 안 된다."
   - **리듬**: 모든 판을 함정으로 만들지 않는다. 한 장은 `배우는 판 → 쉬어 가는 판 → 시험` 으로 긴장과 풀림을 번갈아 준다.
   - **쉬어 가는 판**은 요령을 몰라도 막히지 않아야 한다 (random·greedy 자동 플레이 모두 클리어). 대신 🎁 선물처럼 "얻는 재미"를 넣는다.
   - **초반(1장)은 실수를 버틸 여유**를 준다: 칸 4~5개. 요령을 몰라도 대개 깨지고, 알면 더 매끄럽게 깨지는 정도.
   - 요령을 모르면 반드시 막히는 판(원칙 3의 "강제")은 장마다 꼭 필요한 만큼만 두고, 그 판에는 실패 화면 💡 hint 와 부스터 이어하기가 받쳐 준다.

### 5.C 플레이어 모델 (검증용 전략)
| 전략 | 행동 | 뜻 |
|---|---|---|
| random | 빈 칸이 생기면 아무거나 | 처음 하는 사람 |
| greedy | 닿는 색이면 바로 넣음 | "먹을 수 있는 색"까지만 아는 사람 (1장 2·3번 레슨) |
| full | 닿는 음식으로 숫자를 다 채울 수 있는 쇠똥구리부터, 모자라면 기다림 | 1장을 다 배운 사람 |
| chainWait | full + ① 쓸 만한 사슬이 맨 위면 빈 칸 2개가 될 때까지 기다렸다 넣기 | 2장 요령 중 "칸 2개 비우기"만 아는 사람 |
| chainFree | full + ② 사슬 한쪽만 맨 위면 짝을 가린 줄을 먼저 꺼내기 | 2장 요령 중 "짝 꺼내기"만 아는 사람 |
| chain | full + ① + ② | 2장을 다 배운 사람 |
| key | full + "🔑까지 가장 적게 먹고 가는 길" 위의 색을 먼저 고름 (그 색이면 숫자가 모자라도, 빈 칸이 2개 이상일 때 넣음) | 3장: 열쇠를 노리는 사람 |
| solve | 고르기·기다리기를 모두 탐색 | "풀 수 있음" 증명 (시뮬) |

### 5.D 1장: 기본 (1~6, 기믹 없음) — "누구를 언제 일터에 넣을까"
흐름: 조작 → 못 먹는 색은 두기 → 칸이 줄어듦 → 숫자 보기 → 쉬어 가기 🎁 → 시험. 실패율은 실제 엔진 자동 플레이 8회 (2026-11-12 측정).

| # | 그림 | 칸 | 역할 | 배울 것 | random / greedy / full |
|---|---|---|---|---|---|
| 1 | 하트 풍선 | 5 | 소개 | 조작 (아무렇게나 해도 됨) | 13% / 0% / 0% |
| 2 | 버섯 | 5 | 배움 | 지금 못 먹는 색은 넣지 않기 — 칸 5개라 실수해도 거의 안 막힘 | 13% / 0% / 0% |
| 3 | 과일 바구니 | 4 | 배움 | 칸이 4개로 줄어듦 — 2번 레슨을 조금 더 신경 써서 | 38% / 0% / 0% |
| 4 | 열대어 | 4 | 배움 | **숫자 보기**: 닿는 음식보다 숫자가 크면 💤 칸을 막음 → 길을 여는 쇠똥구리 먼저 | 38% / 13% / 0% |
| 5 | 꽃 | 5 | 쉬어 가기 🎁 | 넉넉한 칸에서 숫자 보기 연습 + 그림 속 선물 (🎁 소개 창이 여기서 처음 뜸) | 25% / 0% / 0% |
| 6 ⚠ | 아이스크림 | 4 | 시험 | 1장에서 배운 것 전부 | 88% / 25% / 0% |

완화 전(2026-11-11)과 비교: 2번 칸 4 → 5, 3·4·6번 칸 3 → 4, 5번 칸 4 → 5.
3번 random 90% → 38%, 4번 greedy 70% → 13%, 5번 greedy 60% → 0%, 6번 greedy 70% → 25%.
6번은 아무거나 누르면 여전히 대부분 막히지만(88%), "닿는 색부터"만 지켜도 4번 중 3번은 깬다.

레슨용 생성 손잡이 (`stages[n].gen`): `pull`(못 먹는 색을 앞으로), `trap`(숫자가 닿는 음식보다 큰 쇠똥구리를 앞으로), `safeTop`(시작 맨 위 3마리 보호), `busy`(생성 시 동시에 일하는 칸), `big`(숫자 상한 배수).

### 5.E 2장: 사슬 (7~12) — "지금 참아야 다음에 넣을 수 있다"
시간 제한이 없어서 "칸 2개 필요"만으로는 늦어질 뿐 막히지 않는다. 그래서 사슬 짝을 **서로 다른 높이**에 걸었다(엇갈린 사슬, `gen.skew`).
한쪽만 맨 위에 오면 그 줄이 막히고, 짝을 꺼내려면 다른 줄을 비워야 한다 → 진짜 고민이 생김.

흐름: 소개 → 만나 보기 → 쉬어 가기 🎁 → 연습 → 쉬어 가기 → 시험(유일한 강제). 실패율은 실제 엔진 자동 플레이 8회 (2026-11-12 측정).

| # | 그림 | 칸 | 역할 | 배울 것 | random / greedy / full / chainWait / chainFree / chain |
|---|---|---|---|---|---|
| 7 | 집 | 5 | 소개 | 🔗 사슬 소개 (같은 높이 사슬 5개, 소개 창) | 전부 0% |
| 8 | 줄무늬 고양이 | 4 | 만나 보기 | 엇갈린 사슬을 처음 봄 — 닿는 색부터 고르면 막히지 않음 | 38 / 0 / 0 / 0 / 0 / 0% |
| 9 | 사과나무 언덕 | 4 | 쉬어 가기 🎁 | 엇갈린 사슬이 있어도 막히지 않는 판에서 편하게 연습 + 선물 | 전부 0% |
| 10 | 무지개 | 4 | 연습 | 짝을 가린 줄 먼저 꺼내기 + 1장 숫자 함정. 시작 배너 `💡 짝을 찾아요`. 아무거나 누르면 절반쯤 막히지만 닿는 색부터 고르면 막히지 않음 | 50 / 0 / 0 / 0 / 0 / 0% |
| 11 | 딸기 소풍 | 5 | 쉬어 가기 | 칸 5개, 사슬이 있어도 여유 있게 풀림 (시험 전 숨 고르기) | 전부 0% |
| 12 ⚠ | 로켓 | 4 | 시험 | 숫자 보기 + 짝 꺼내기 + 칸 2개 비우기 | 0 / 0 / 100 / 100 / 100 / **0%** |

완화 전과 비교: 칸 3 → 4 (8·9·10·12), 11번은 칸 4 → 5. 요령을 모르면 반드시 막히는 판이 5개(8~12) → 1개(12번 시험).

알아 둘 점 (다음 조정 후보)
- 엇갈린 사슬 함정은 "걸리면 100%, 아니면 0%"로 갈린다(순서가 정해진 구조라 중간이 없음). 그래서 8번은 처음엔 요령 두 가지를 다 써야만 풀리는 벽(아무거나 눌러도 100% 막힘)이었는데, 막히지 않는 판으로 바꾸고 첫 강제를 10번으로 미뤘다.
- 10번도 처음엔 벽(아무거나 100%, 닿는 색만 75% 막힘)이었는데 같은 이유로 막히지 않는 판으로 바꿨다. 이제 2장에서 요령이 꼭 필요한 판은 **12번 시험 하나**다.
- 그 대가로 "강제" 단계(원칙 1)가 2장에서는 시험 전에 없다: 짝 꺼내기·칸 2개 비우기는 8~11번에서 겪어 보고 실패 화면 💡 로 배우는 정도. 12번에서 처음으로 꼭 필요해지므로, 12번 체감이 갑자기 가파르지 않은지 사람 플레이로 확인할 것 (12번은 random·greedy 0%, full 100%).
- "빈 칸 2개 비워 두기"만으로 갈리는 판은 없앴다: 칸 4개에서 그런 판(seed)이 없음. 이 요령은 12번 시험에서 다른 요령과 함께 필요하고, 8·9·10번 실패 화면 💡 에서 알려 준다. 8번과 9번이 "서로 반대 요령만 통하는 짝"이던 구성은 사라짐.
- 12번은 random·greedy 가 0%인데 full 은 100%: "숫자가 모자라면 기다리는" 습관이 사슬 판에서는 오히려 줄을 막는 경우. 시험으로서는 chain 전략만 0%이면 되지만, 사람에게 얼마나 어려운지는 직접 플레이로 확인 필요.
- `giftAt`(🎁)을 넣으면 생성 결과가 달라진다 → 선물을 넣은 판은 seed 를 다시 재야 함 (9번은 선물을 넣자 함정 판이 되어 seed 를 다시 골랐음).

보상: 장 시험 클리어 선물 (6 → ↩ 돌려보내기, 12 → ✂ 사슬 끊기) + 쉬어 가는 판의 🎁 (5·9번, 부스터 1개 무작위).

### 5.F 3장: 열쇠 🔑 (13~20) — "열쇠를 먹으면 일터가 넓어진다"
잠긴 일터 칸(자물쇠)으로 **좁게 시작**하고, 그림 속 🔑 음식을 가져올 때마다 한 칸씩 열린다.
난이도로 조이는 장이 아니라 "좁다 → 열쇠 → 넓어진다"는 **풀림의 재미**를 주는 장이다 (원칙 6).
🔑은 그림 안쪽 깊은 곳에 둔다(`gen.keyDeep`) → 어느 색을 먹어야 열쇠까지 길이 나는지 읽게 됨.

흐름: 소개 → 깊은 열쇠 → 쉬어 가기 🎁 → 열쇠 2개 → 사슬 조합 → 쉬어 가기 🎁 → 두 칸으로 시작 → 시험. 실패율은 실제 엔진 자동 플레이 8회 (2026-11-12 측정).

| # | 그림 | 시작 칸 → 다 열면 | 🔑 | 역할 | 배울 것 | random / greedy / full / key |
|---|---|---|---|---|---|---|
| 13 | 목도리 펭귄 | 3 → 4 | 1 (얕음) | 소개 | 🔑을 가져오면 잠긴 일터가 열림 (소개 창) | 25 / 0 / 0 / 0% |
| 14 | 수박 | 3 → 4 | 1 (깊음) | 배움 | 열쇠가 안쪽에 — 길을 막은 색부터. 배너 `💡 깊은 곳의 열쇠` | 38 / 0 / 0 / 0% |
| 15 | 나비 | 4 → 5 | 1 | 쉬어 가기 🎁 | 열쇠와 선물을 모두 챙기는 넉넉한 판 | 0 / 0 / 0 / 0% |
| 16 | 케이크 | 3 → 5 | 2 | 배움 | 열쇠 2개: 가까운 것부터 열고, 숫자 함정은 칸이 넓어진 뒤에. 배너 `💡 열쇠가 2개!` | 63 / 0 / 0 / 0% |
| 17 | 거북이 | 4 → 5 | 1 | 조합 | 사슬(칸 2개 필요) + 열쇠 — 안내 없이 | 38 / 0 / 0 / 0% (chain 0%) |
| 18 | 해님 | 4 → 5 | 1 | 쉬어 가기 🎁 | 시험 전 숨 고르기 | 13 / 0 / 0 / 0% |
| 19 | 우산 | 2 → 4 | 2 | 연습 | 칸 2개뿐 — 한 마리만 막혀도 위험, 열쇠부터. 배너 `💡 칸이 2개뿐!` | 63 / 25 / 0 / 0% |
| 20 ⚠ | 자동차 | 2 → 5 | 3 | 시험 | 숫자 보기(1장) + 열쇠로 칸 늘리기. 보상 🔓 일터 열쇠 | 100 / 50 / 0 / 0% |

**알아 둘 점: "열쇠를 노려야만 풀리는" 판은 만들지 못했다.**
- 원래 계획은 "열쇠를 늦게 먹으면 막히는 판"(key 전략 0%, 앞 장 전략은 막힘)이었다. 그런데 설정 6가지 × seed 60여 개를 재 본 결과 **key 전략이 full 전략보다 나은 판이 하나도 없었다** (둘 다 0%이거나 둘 다 막힘).
- 이유: 🔑은 특별한 행동이 필요한 게 아니라 그냥 음식이라, 그 색 쇠똥구리가 일하다 보면 어차피 먹힌다. 그리고 full(닿는 음식으로 숫자를 채울 수 있을 때만 넣기)은 칸을 막지 않으므로, 칸이 좁아도 기다리면 풀린다.
- 그래서 3장의 열쇠는 "꼭 풀어야 하는 문제"가 아니라 **"빨리 먹을수록 편해지는 보상"**이다. 시험(20)도 "아무거나 누르면 100% 막히고, 닿는 색만 보면 절반 막히고, 숫자까지 보면(1장) 풀린다"로 검증했다 — 3장 고유의 요령을 강제하지는 않는다.
- 열쇠를 진짜 고민거리로 만들려면 규칙이 더 필요하다. 후보: ① 열쇠 색 쇠똥구리가 대기열에 **한 마리뿐**이라 그걸 다른 음식에 써 버리면 열쇠를 못 먹음(숫자 = 열쇠까지 거리), ② 시작 칸 1개(열쇠를 먹기 전엔 한 번에 한 마리), ③ 열쇠를 먹어야만 나오는 색. 5장(⛓ 잠긴 줄: 열린 두 줄로만 열쇠까지 가기)이 이 고민을 다루는 자리이기도 하다.

### 5.0 허들 = 숫자가 아니라 "작전"
허들은 그냥 어렵게(순서를 더 섞고 칸을 줄이는 것)만 만들면 답답할 뿐 재미가 없다.
그래서 **그림 속에 장치(기믹)를 숨겨서 "어디부터 먹을지" 작전을 세우게** 만든다.
기믹은 하나씩 소개하고(첫 등장 스테이지에서 소개 창), 익숙해지면 섞어서 보스에 낸다.

| 기믹 | 첫 등장 | 규칙 | 플레이어의 작전 |
|---|---|---|---|
| 🔑 열쇠 음식 | 13 (3장) | 그림 속 🔑 음식을 쇠똥구리가 가져오면 자물쇠가 하나 열림 (잠긴 일터 칸 → 잠긴 줄 순서) | 열쇠까지 길을 내는 색을 먼저 골라 일터를 빨리 넓힌다 |
| 🎁 선물 음식 | 5 | 🎁 음식을 가져오면 부스터 1개 (돌려보내기/폭탄/사슬 끊기/열쇠 중 무작위, 혼자 하기) | 위험해도 선물 쪽부터 파고들까? 보상과 안전의 저울질 |
| 🧊 얼음 음식 | 12 | 얼어 있는 음식은 못 가져가고 길도 막음. 바로 옆 음식이 먹히면 깨짐 | 얼음 옆 음식을 먼저 먹어 녹여야 안쪽 길이 열림 |
| ⛓ 잠긴 줄 | 22 | 오른쪽 대기열 줄에 자물쇠. 🔑을 먹으면 풀림 | 열린 두 줄의 쇠똥구리만으로 열쇠까지 가는 길을 찾아야 함 |

| 스테이지 | 기믹 |
|---|---|

| 22 | ⛓ 잠긴 줄 — 소개, 이후 4로 나눠 2가 남는 스테이지에 가끔 |

생성 규칙 (항상 풀 수 있게)
- 1차 시뮬레이션으로 "음식이 먹히는 순서"를 구하고, 그 순서의 `keyAt` % 지점 음식에 🔑, `giftAt` % 지점 음식에 🎁을 숨긴다 → 열쇠가 너무 쉽거나 영영 못 닿는 곳에 놓이지 않음.
- 2차 시뮬레이션은 🔑을 먹는 순간 일터가 넓어지는 것까지 흉내 내서 쇠똥구리 순서를 만든다.
- ⛓ 잠긴 줄에는 그 줄이 풀린 뒤에 고를 쇠똥구리만 넣고, 잠긴 줄에는 사슬을 걸지 않는다.
- 🧊 얼음은 옆에 얼음 아닌 음식이 있는 칸에만 놓고, 시뮬레이션에서 막히면 얼음 수를 줄여 다시 만든다.

보조 손잡이 (기믹과 함께 조금씩)
- **먼 순서 뒤섞기 (`jitterSpan`)**, **사슬 증가 (`linkAdd`)**, **쇠똥구리 수 증가 (`antMul`)**

## 6. 부스터 (보관형 아이템) ★
기존에는 숨은 아이템이 스테이지마다 3~9개 자동 발동해서 난이도를 깎아 먹었다.
→ **혼자·협동에서는 숨은 아이템을 없애고**, 드물게 선물로 주는 **보관형 부스터**로 바꿈.
플레이어는 부스터를 모아 두었다가 "도저히 안 풀리는" 스테이지에서 꺼내 쓴다.

| 부스터 | 효과 | 쓸 수 있는 때 |
|---|---|---|
| ↩ 돌려보내기 | 일터 쇠똥구리 하나(못 움직이는 쇠똥구리 우선)를 가장 짧은 대기열 맨 아래로 | 일터에 쇠똥구리가 있을 때 · **실패 화면에서 이어하기** |
| 🔓 일터 열쇠 | 자물쇠 하나를 바로 엶 (그림 속 🔑을 못 먹었을 때) | 자물쇠가 있을 때 · **실패 화면에서 이어하기** |
| ✂ 사슬 끊기 | 대기열의 모든 사슬을 풂 | 사슬이 있을 때 |
| 💣 폭탄 | 그림의 원하는 곳을 눌러 주변 3×3 음식 제거 (쇠똥구리 숫자도 맞춰 줄임) | 언제나 (조준 후 사용) |

- 쓰는 곳: 플레이 화면 상단 바의 `🎒` 버튼(◀ 옆, 개수 배지) → 가방 창 (보는 동안 일시정지) / 실패 화면의 이어하기 버튼.
- 혼자 하기 전용 (협동·경쟁은 동기화·공정성 때문에 사용 불가).
- 보관 상한: 종류마다 9개. 진행도와 함께 기기에 저장.

### 6.1 획득 (클리어 선물, 처음 깰 때만)
| 조건 | 선물 |
|---|---|
| 게임 처음 시작 | ↩ 돌려보내기 1 |
| 보스 바로 앞 스테이지(29·39·49) 클리어 | ↩ 돌려보내기 1 — "다음은 보스니까 아껴 둬" |
| 보스(30·40·50) 클리어 | 🔓 열쇠 → 💣 폭탄 → ✂ 사슬 끊기 순환 1개 |
| 장 시험(6·12·20) 클리어 | 6 → ↩ 돌려보내기 1, 12 → ✂ 사슬 끊기 1, 20 → 🔓 일터 열쇠 1 |
| 그림 속 🎁 음식 (5·9·15·18번 등) | 부스터 1개 무작위 (처음이 아니어도 먹을 때마다) |
→ 클리어 화면에 `🎁 선물: …` 표시.

### 6.2 숨은 아이템 (경쟁 온라인 전용)
대결의 변수로만 남김: ⚡질주 / ✂사슬 끊기 / 💣폭탄 / 🐌방해(상대 느려짐). 스테이지당 4개부터 10스테이지마다 +1 (최대 8).
