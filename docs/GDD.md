# 데굴데굴 쇠똥구리 — 게임 기획서 (GDD)

> 버전 2 · 2026-11-09 · 밸런스 값의 실제 숫자는 `balance/balance.js`, 테이블 구조는 [balance-tables.md](balance-tables.md)

## 1. 개요
| 항목 | 내용 |
|---|---|
| 장르 | 캐주얼 순서 퍼즐 (대기열 선택 + 길 열기) |
| 플랫폼 | 모바일 웹 (세로 420×800, 단일 HTML) |
| 한 판 | 1~3분 |
| 핵심 재미 | "지금 누구를 일터에 보낼까?" — 순서를 잘못 고르면 일터가 막힘 |
| 콘텐츠 | 기본 52스테이지 (도트 그림 32 + 큰 그림 20) + 📷 내 사진 스테이지 |
| 모드 | 혼자 하기 / 협동 온라인 / 경쟁 온라인 (PeerJS 폰끼리 연결) |

## 2. 화면 구성
- **위 2/3 그림판**: 음식 조각으로 그려진 그림. 바깥에 쇠똥구리가 다니는 네모 길.
- **일터 5칸**: 대기열에서 고른 쇠똥구리가 들어가는 자리. 칸 위에 집(일꾼이 나오는 곳).
- **대기열 3줄**: 맨 위 쇠똥구리만 고를 수 있음. 숫자 = 가져올 음식 수.
- **굴**: 그림판 아래 가운데. 일꾼이 음식을 굴려 넣는 곳.
- **상단 바**: 뒤로, 스테이지 이름(허들은 ⚠/🔥 표시), 진행 막대, 배속(1·2·3·5·9), 다시.

## 3. 핵심 규칙
1. 대기열 맨 위 쇠똥구리를 누르면 빈 일터로 감.
2. 일터 쇠똥구리는 숫자만큼 일꾼을 0.4초 간격으로 내보냄.
3. 일꾼은 집 → 바깥 네모 길 → **그림 바깥과 이어진 빈 칸**을 따라 꺾어 들어가 같은 색 음식을 집음.
   (바깥에서 닿지 않는 음식은 못 가져감 = 바깥쪽부터 먹어야 안쪽 길이 열림)
4. 집은 음식은 공처럼 굴려 가장 가까운 출구로 나가 굴로 넣음.
5. 일꾼을 다 보낸 일터 쇠똥구리는 사라져 칸이 빔.
6. **사슬**: 같은 줄 이웃 두 쇠똥구리가 묶이면 둘 다 맨 위에 있고 빈 칸이 2개 있어야 고를 수 있음.
7. **클리어**: 음식을 모두 굴로 옮김. **실패**: 일하는 일꾼이 없고, 일터 쇠똥구리가 닿을 음식이 없고, 더 고를 수도 없음 (0.9초 유지).

### 3.1 이동 연출 규칙
- 마주 오는 쇠똥구리와 겹치지 않게 진행 방향 오른쪽으로 차선을 비켜 걸음.
- **바깥 네모 길 위에서는 방향과 상관없이 항상 그림 안쪽으로 비켜 걸음** (액자 테두리 선을 밟지 않음).
- 같은 방향 앞 쇠똥구리와 안전거리 유지, 집 앞이 붐비면 출발 대기.

## 4. 스테이지 생성
- 그림 → 음식 격자 (최대 28×30칸, 테두리선 포함).
- 쇠똥구리 순서는 **실제 플레이를 흉내 낸 시뮬레이션**으로 만듦 → 반드시 풀 수 있는 순서가 기본.
  - 동시에 일하는 칸은 보통 `min(3, 일터칸-1)`, 막히면 일터 칸 수까지.
  - 새 쇠똥구리는 "지금 닿을 수 있는 색"으로만 만든다.
- 이후 난이도 손잡이로 순서를 흔든다:
  - `jitter`: 이웃 쇠똥구리 순서를 바꿀 확률 / `jitterSpan`: 최대 몇 칸 멀리 바꾸는지
  - `link`: 줄마다 사슬이 생길 확률 / `ants`: 목표 쇠똥구리 수
  - `seed`: 같은 값이면 항상 같은 순서 (QA가 고른 값을 표에 고정)

## 5. 난이도 곡선과 허들 ★
퍼즐의 재미는 "막혔다가 뚫는 순간". 캔디크러시처럼 **톱니 모양 곡선**을 쓴다.

```
난이도
  ▲        🔥         🔥         🔥
  │   ⚠   ╱│    ⚠   ╱│    ⚠   ╱│
  │  ╱│ ╱  │   ╱│ ╱  │   ╱│ ╱  │
  │ ╱ │╱   │  ╱ │╱   │  ╱ │╱   │ ...
  └──────────────────────────────▶ 스테이지
     5   10  11 15  20  21 25  30
```

| 등급 | 스테이지 (n=1부터) | 일터 | 의도 |
|---|---|---|---|
| 쉬움 easy | 1~3 (튜토리얼), 11·21·31·41·51 (보스 다음) | 5칸 | 규칙 익히기 / 숨 돌리기 |
| 보통 normal | 나머지 | 5칸 | 기본 곡선을 따라 서서히 어려워짐 |
| 어려움 hard ⚠ | 5·15·25·35·45 | 5칸 (🔑로 여는 자물쇠) | 중간 허들: 새 기믹을 조합한 작전 문제 |
| 보스 boss 🔥 | 10·20·30·40·50 | 5칸 (자물쇠 2~3개) | 큰 허들: 기믹 여러 개 + 🎁 보상 |

### 5.0 허들 = 숫자가 아니라 "작전"
허들은 그냥 어렵게(순서를 더 섞고 칸을 줄이는 것)만 만들면 답답할 뿐 재미가 없다.
그래서 **그림 속에 장치(기믹)를 숨겨서 "어디부터 먹을지" 작전을 세우게** 만든다.
기믹은 하나씩 소개하고(첫 등장 스테이지에서 소개 창), 익숙해지면 섞어서 보스에 낸다.

| 기믹 | 첫 등장 | 규칙 | 플레이어의 작전 |
|---|---|---|---|
| 🔑 열쇠 음식 | 5 ⚠ | 그림 속 🔑 음식을 쇠똥구리가 가져오면 자물쇠가 하나 열림 (잠긴 일터 칸 → 잠긴 줄 순서) | 열쇠까지 길을 내는 색을 먼저 골라 일터를 빨리 넓힌다 |
| 🎁 선물 음식 | 8 | 🎁 음식을 가져오면 부스터 1개 (돌려보내기/폭탄/사슬 끊기/열쇠 중 무작위, 혼자 하기) | 위험해도 선물 쪽부터 파고들까? 보상과 안전의 저울질 |
| 🧊 얼음 음식 | 12 | 얼어 있는 음식은 못 가져가고 길도 막음. 바로 옆 음식이 먹히면 깨짐 | 얼음 옆 음식을 먼저 먹어 녹여야 안쪽 길이 열림 |
| ⛓ 잠긴 줄 | 22 | 오른쪽 대기열 줄에 자물쇠. 🔑을 먹으면 풀림 | 열린 두 줄의 쇠똥구리만으로 열쇠까지 가는 길을 찾아야 함 |

기믹 등장표 (`gimmickRules`)
| 스테이지 | 기믹 |
|---|---|
| 5 ⚠ | 🔑×1 (잠긴 일터 1칸) — 열쇠 소개 |
| 8 | 🎁×1 — 선물 소개 |
| 10 🔥 | 🔑×2 (잠긴 일터 2칸) · 🎁 |
| 12 | 🧊 — 얼음 소개, 이후 3의 배수 보통 스테이지에 가끔 |
| 15 ⚠ | 🔑 + 🧊 많이 |
| 20 🔥 | 🔑 + 🧊 + 🎁 |
| 22 | ⛓ 잠긴 줄 — 소개, 이후 4로 나눠 2가 남는 스테이지에 가끔 |
| 25 ⚠ | 🔑×2 (일터 + 줄) |
| 30 🔥 | 🔑×2 + ⛓ + 🧊 + 🎁 |
| 35 ⚠ | ⛓ + 🧊 많이 |
| 40 🔥 | 🔑×2 (일터 2칸) + 🧊 + 🎁 |
| 45 ⚠ | 🔑×2 + ⛓ + 🧊 |
| 50 🔥 | 전부: 🔑×3 + ⛓ + 🧊 + 🎁×2 |

생성 규칙 (항상 풀 수 있게)
- 1차 시뮬레이션으로 "음식이 먹히는 순서"를 구하고, 그 순서의 `keyAt` % 지점 음식에 🔑, `giftAt` % 지점 음식에 🎁을 숨긴다 → 열쇠가 너무 쉽거나 영영 못 닿는 곳에 놓이지 않음.
- 2차 시뮬레이션은 🔑을 먹는 순간 일터가 넓어지는 것까지 흉내 내서 쇠똥구리 순서를 만든다.
- ⛓ 잠긴 줄에는 그 줄이 풀린 뒤에 고를 쇠똥구리만 넣고, 잠긴 줄에는 사슬을 걸지 않는다.
- 🧊 얼음은 옆에 얼음 아닌 음식이 있는 칸에만 놓고, 시뮬레이션에서 막히면 얼음 수를 줄여 다시 만든다.

보조 손잡이 (기믹과 함께 조금씩)
- **먼 순서 뒤섞기 (`jitterSpan`)**, **사슬 증가 (`linkAdd`)**, **쇠똥구리 수 증가 (`antMul`)**

허들 안내: 메뉴 카드에 ⚠ 어려움 / 🔥 보스 태그, 시작 배너에 기믹 요약(예: `🔑×2 · 🧊 얼음 · 🎁×1 — 작전을 세워요!`), 새 기믹 소개 창(한 번만).

### 5.1 QA 목표 (시뮬레이터 기준 실패율)
| 등급 | 아무거나 누르는 초보 | 먹을 수 있는 색만 고르는 보통 | 풀 수 있음 |
|---|---|---|---|

| normal | ≤ 35% | ≤ 8% | 필수 |

## 6. 부스터 (보관형 아이템) ★
기존에는 숨은 아이템이 스테이지마다 3~9개 자동 발동해서 난이도를 깎아 먹었다.
→ **혼자·협동에서는 숨은 아이템을 없애고**, 드물게 선물로 주는 **보관형 부스터**로 바꿈.
플레이어는 부스터를 모아 두었다가 "도저히 안 풀리는" 스테이지에서 꺼내 쓴다.

| 부스터 | 효과 | 쓸 수 있는 때 |
|---|---|---|
| ↩ 돌려보내기 | 일터 쇠똥구리 하나(못 움직이는 쇠똥구리 우선)를 가장 짧은 대기열 맨 아래로 | 일터에 쇠똥구리가 있을 때 · **실패 화면에서 이어하기** |
| 🔓 일터 열쇠 | 자물쇠 하나를 바로 엶 (그림 속 🔑을 못 먹었을 때) | 자물쇠가 있을 때 · **실패 화면에서 이어하기** |
| ✂ 사슬 끊기 | 대기열의 모든 사슬을 풂 | 사슬이 있을 때 |
| 💣 폭탄 | 그림의 원하는 곳을 눌러 주변 3×3 음식 제거 (쇠똥구리 숫자도 맞춰 줄임) | 언제나 (조준 후 사용) |

- 쓰는 곳: 플레이 화면 그림판 왼쪽 아래 `🎒 부스터 N` → 가방 창 (보는 동안 일시정지) / 실패 화면의 이어하기 버튼.
- 혼자 하기 전용 (협동·경쟁은 동기화·공정성 때문에 사용 불가).
- 보관 상한: 종류마다 9개. 진행도와 함께 기기에 저장.

### 6.1 획득 (클리어 선물, 처음 깰 때만)
| 조건 | 선물 |
|---|---|
| 게임 처음 시작 | ↩ 돌려보내기 1 |
| 보스 바로 앞 스테이지(9·19·29·39·49) 클리어 | ↩ 돌려보내기 1 — "다음은 보스니까 아껴 둬" |
| 보스(10·20·30·40·50) 클리어 | 🔓 열쇠 → 💣 폭탄 → ✂ 사슬 끊기 순환 1개 |
→ 10스테이지당 약 2개. 클리어 화면에 `🎁 선물: …` 표시.

### 6.2 숨은 아이템 (경쟁 온라인 전용)
대결의 변수로만 남김: ⚡질주 / ✂사슬 끊기 / 💣폭탄 / 🐌방해(상대 느려짐). 스테이지당 4개부터 10스테이지마다 +1 (최대 8).

## 7. 진행 · 저장
- 스테이지는 순서대로 열림 (`antPuzzleCleared`). 마지막 스테이지 이어하기.
- 저장 키: `antPuzzleCleared`, `antPuzzleLast`, `antPuzzleSpeed`, `antPuzzleMode`, `antPuzzleBoosters`.
- 치트: PC `open` 입력 / 폰 제목 5번 톡톡 → 모든 스테이지 열기 (진행도는 그대로).

## 8. 온라인
- 협동: 번갈아 고름. 방장이 게임을 돌리고 손님에게 0.1초마다 상태 전송.
- 경쟁: 같은 그림을 각자 먹고 먼저 다 먹거나 상대가 막히면 승리. 배속 고정.
